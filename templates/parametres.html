Configuration Gmail

Pour utiliser Gmail, vous devez activer l'authentification à deux facteurs et créer un mot de passe d'application :

  1. Activez la vérification en deux étapes sur votre compte Google
  2. Allez dans les paramètres de sécurité de votre compte Google
  3. Créez un "Mot de passe d'application" pour "Mail"
  4. Utilisez ce mot de passe d'application dans le champ ci-dessus
