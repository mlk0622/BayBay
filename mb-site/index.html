BayBay — Gestion Locative Intelligente

Plateforme logicielle complète destinée aux propriétaires bailleurs et SCI. Disponible en version Web (SaaS) et application Bureau Windows rapide. Automatise les quittances de loyer certifiées ALUR, les avis d'échéance, les états des lieux et le suivi de rentabilité avec chiffrement AES-256 bits.

Python (Flask) Electron.js MySQL / SQLite ReportLab / PDF ALUR Chiffrement AES-256

Poudelard — Simulation & Logique Métier
